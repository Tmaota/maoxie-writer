# 码字工坊

一个给网文作者用的跨端写作软件。Windows 桌面版、安卓 App、网页版三端共用一套代码，
数据通过 GitHub 私有仓库在设备之间同步。

## 它能干什么

**写作组织**

- 书架 → 书 → 章节 三层管理，一本书就是一个分类
- 章节模式单章写作；Part 模式把任意几章拼成一篇发布稿，拼稿里改一个字，对应章节同步跟着改
- 阅读模式专门用来审稿，看完回编辑模式光标还在原来的地方

**改稿工具**

- 修订模式：把一章/一个 Part 按字数均分成 N 个部分，逐段定修改目标，改完一段手动确认一段
- 修改记录：每章每 Part 各自记账，改了哪里一目了然，可以一键回退
- 跳转提醒：从记录跳回正文时目标行自动滚到屏幕正中，整行高亮闪烁 5 秒
- 时光机：每章自动保存历史版本，误删误改能找回来

**写作体验**

- 章节状态标记：草稿 / 已发布 / 待修改
- 自定义词组：输入触发词按空格自动替换成整段文本（比如发布平台的分页符号）
- ADHD 辅助阅读：只显示光标上下各两行、当前行高亮，多种辅助可单独开关、高亮色自选
- 字数统计、本章目标字数、每日码字热力图
- 重开 App 自动回到关闭前的章节、滚动位置和光标

**多设备**

- GitHub 登录，书稿 + 设置 + 背景图一起同步到私有仓库
- 自动同步：检测到有改动才上传，手动保存随时接管
- 桌面挂件：把某一章或某个 Part 放到手机桌面，点开直达正文

**外观**

- 日间 / 夜间 / 跟随系统三种主题
- 20 种正文字体、自定义背景图与透明度（手机端单独一套背景）
- 快捷键自定义、导入导出路径自定义

## 技术栈

| 层 | 选型 |
| --- | --- |
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui |
| 桌面端 | Electron（主进程代理 GitHub API，绕开浏览器 CORS） |
| 手机端 | Capacitor 打包安卓 App（含桌面 AppWidget 挂件） |
| 云端 | GitHub REST API + Git Data API（超 1MB 的存档自动走 git 对象，绕过 contents API 体积限制） |
| 文档 | 导入导出 TXT / DOCX / MD |

## 目录结构

```
src/
  pages/Home.tsx        主页与状态中枢（模式切换、云端同步调度、快捷键）
  components/           编辑器、阅读视图、目录、面板、弹窗、手机外壳
  components/ui/        shadcn/ui 基础组件
  lib/                  存储、拼稿、修订、字数、词组、GitHub 云端等核心逻辑
  hooks/                移动端断点判断
electron/               桌面端主进程 + 预加载
android/                Capacitor 安卓工程
```

每个源码文件顶部都有一行 `这部分负责: …` 说明这个模块干嘛的，
模块之间用颜文字分界线隔开（个人习惯，不影响任何功能）。

## 本地运行

```bash
npm install
npm run dev        # 开发预览
```

打包发布走 `electron-builder`（Windows 安装版）和 Gradle（APK），
详细脚本见 package.json 与 android/ 工程。
